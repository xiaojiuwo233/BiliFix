# BiliFix

针对新版国际版（6.2.6）以上的版本实验性修复分支，低优先级维护状态，详见[关于新版bilibili国际版的说明](https://github.com/xiaojiuwo233/BiliFix/issues/6)。

> 自用模块，不保证其稳定性，欢迎各位大佬贡献！

### 如果本模块对你有所帮助，欢迎点个[Star](https://github.com/xiaojiuwo233/BiliFix)，十分感谢！
### 请先阅读完整的[关于新版bilibili国际版的说明](https://github.com/xiaojiuwo233/BiliFix/issues/6)后再使用，此版本与旧版不兼容！

## 兼容性

- 仅支持哔哩哔哩国际版 `(com.bilibili.app.in)` 6.2.6、6.3.0
- Xposed API 101 或更高版本

## 功能

功能设置入口已集成进应用内设置

### 修复

- 恢复直播Tab
- 完整竖屏模式入口
- 游戏中心入口

### 增强

- 消息按钮移动到首页
- 显示IP属地
- 评论与视频简介自由复制

## 已知问题

- 模块功能目前不完善，可能会出现闪退/功能无效等问题，请斟酌后使用
